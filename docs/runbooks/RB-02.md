# RB-02 — Budget, turn limit, step-retry or Judge-retry budget exhausted

Source: HLD v0.5 §9.1. Exercised by the degradation suite (§10.2) by following these steps.

**Two rules hold in every runbook.** Never restore service by weakening a control (disabling the
sandbox, relaxing a budget, raising a rate cap, skipping a check, hand-editing a bundle). A needed
change goes through change control (plan §17.1). `handed_off` episodes are never reopened.

| | |
|---|---|
| Trigger | Budget, turn limit, step-retry or Judge-retry budget exhausted |
| Automatic behaviour | handed_off + alert naming the cause. |
| Operator actions | Handle the incident by hand. Log it for the weekly review (AW-6). If it recurs, file a change request against P-05 / P-06 / P-08 / P-09. |
| Exit condition | Per episode; none system-wide. |
| Where to look | episode `steps[]`, `state_history[-1].reason` |
