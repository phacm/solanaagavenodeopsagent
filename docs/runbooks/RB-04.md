# RB-04 — Bundle revoked, or drain deadline exceeded

Source: HLD v0.5 §9.1. Exercised by the degradation suite (§10.2) by following these steps.

**Two rules hold in every runbook.** Never restore service by weakening a control (disabling the
sandbox, relaxing a budget, raising a rate cap, skipping a check, hand-editing a bundle). A needed
change goes through change control (plan §17.1). `handed_off` episodes are never reopened.

| | |
|---|---|
| Trigger | Bundle revoked, or drain deadline exceeded |
| Automatic behaviour | Bound episodes -> handed_off; outstanding tokens refused. |
| Operator actions | Handle the affected incidents by hand. Confirm which bundle is now active (`valops bundle list`). |
| Exit condition | No live episode is bound to a revoked bundle. |
| Where to look | `bundles/revoked`, `active.history` |
