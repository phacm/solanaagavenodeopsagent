# RB-07 — Episode store unavailable

Source: HLD v0.5 §9.1. Exercised by the degradation suite (§10.2) by following these steps.

**Two rules hold in every runbook.** Never restore service by weakening a control (disabling the
sandbox, relaxing a budget, raising a rate cap, skipping a check, hand-editing a bundle). A needed
change goes through change control (plan §17.1). `handed_off` episodes are never reopened.

| | |
|---|---|
| Trigger | Episode store unavailable |
| Automatic behaviour | Controller aborts the step; alert; nothing assumed written. |
| Operator actions | Restore the service. If data is lost, restore from backup (plan §17.3) and verify revisions. |
| Exit condition | Store up; idempotent retries replayed without duplicates. |
| Where to look | store socket; sqlite backup |
