# RB-13 — Ops host down

Source: HLD v0.5 §9.1. Exercised by the degradation suite (§10.2) by following these steps.

**Two rules hold in every runbook.** Never restore service by weakening a control (disabling the
sandbox, relaxing a budget, raising a rate cap, skipping a check, hand-editing a bundle). A needed
change goes through change control (plan §17.1). `handed_off` episodes are never reopened.

| | |
|---|---|
| Trigger | Ops host down |
| Automatic behaviour | Watchtower-only tier. Watchtower runs on a third host so it survives this case. |
| Operator actions | Restore the ops host from backup (plan §17.3). Verify both chains against the anchor before re-enabling LLM steps. |
| Exit condition | Restore verified; all probes healthy. |
| Where to look | watchtower |
